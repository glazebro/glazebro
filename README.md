## What I do

- **Frontend, first.** I build a multi-tenant page-builder platform in React, TypeScript and Next.js: the editor and content blocks, UI quality, accessibility, and Playwright end-to-end tests.
- **Full-stack with AI agents.** Agents extend my work from the UI through Next.js API routes, SQL Server schema and Flyway migrations, auth and sessions, upstream API integrations, Azure and CI.
- **Agentic engineering.** I run Claude Code as an engineering team, not a chat window. Agents build, test, review and ship in multi-agent pipelines, with human approval gates between stages, and verify their results against the live system.
- **Multi-model code review.** Claude, GitHub Copilot and OpenAI Codex check each other's work. PR review fixes are made test-first, with proof that each regression test fails without the fix.
